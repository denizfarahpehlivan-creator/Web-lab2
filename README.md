# Web Lab 2 – CSS

##  Project Description
In this assignment, CSS was used to style HTML elements and practice the **CSS Box Model**.
The main purpose of the assignment is to understand how CSS properties such as:

* `margin`
* `padding`
* `border`
* `width`
* `height`
* `box-sizing`

affect the size, position, and appearance of HTML elements.

## CSS Topics Practiced

### Margin
Used to create space outside an element's border.

### Padding
Used to create space between an element's content and its border.

### Border
Used to create a visible boundary around an element.

### Box Model
The CSS box model consists of:

```text
Content
   ↓
Padding
   ↓
Border
   ↓
Margin
```

### Box-Sizing
The `box-sizing` property was also practiced to understand how the declared width and height of an element are calculated.
